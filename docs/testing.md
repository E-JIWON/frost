# 테스트와 측정

Frost는 세 가지로 확인한다.

1. **자체 검사**: 포커스 · 제외 · 그룹 규칙을 코드로 확인한다. 빌드할 때마다, 그리고 깃헙에 올릴 때마다 돈다
2. **측정**: `bench/run.sh`로 반응 속도와 CPU · 메모리를 잰다
3. **직접 확인**: 화면을 봐야 알 수 있는 것들. 확인 방법과 마지막으로 확인한 날짜를 적는다

## 1. 자체 검사

```bash
./build.sh                                   # 빌드하면서 돈다. 실패하면 설치하지 않는다
Frost.app/Contents/MacOS/Frost --selftest    # 따로 돌릴 때
```

깃헙 Actions(`.github/workflows/check.yml`)가 커밋마다 macOS에서 빌드하고 자체 검사를 돌린다. Swift 6 언어 모드로도 컴파일해서, 스레드를 잘못 쓰는 코드가 들어오면 바로 실패한다. README 맨 위 배지가 그 결과다.

| 영역 | 확인하는 것 |
|---|---|
| 머물면 흐림 줄이기 | 흐린 곳에 0.5초 머물면 옅어진다 · 선명한 창으로 옮기면 바로 돌아온다 · 다시 머물면 0.5초를 처음부터 센다 |
| 포커스 | 맨 위 창 아래에 깔리고 나머지는 흐리다 · 제외한 앱은 맨 앞에 와도 포커스를 가져가지 않는다 |
| 앱 제외 | 제외한 앱의 창은 모두 선명하다 · 다른 창에 가린 부분은 흐리다 · 다른 앱 창은 흐리다 |
| 앱 그룹 | 그룹 앱의 맨 위 창은 선명하다 · 그 앱의 나머지 창은 흐리다 · 다른 창에 가린 부분은 흐리다 · 지금 쓰는 앱이 없는 그룹은 아무 일도 안 한다 |
| 화면별 포커스 | 켜면 화면마다 자기 맨 위 창이 선명하다 · 끄면 모든 화면이 맨 앞 창 하나를 따른다 · 창이 없는 화면은 덮지 않는다 |
| 전체 화면 | 화면을 꽉 채운 창이 있으면 그 화면은 덮지 않는다 · 다른 화면은 그대로 덮는다 |

모두 17개 항목이다.

## 2. 측정

Frost를 켠 상태에서:

```bash
./bench/run.sh
```

30초쯤 걸린다. 테스트 창이 열렸다 닫히니 끝날 때까지 마우스와 키보드를 놓는다. 끝나면 아래 표 모양 그대로 출력한다.

| 측정 | 무엇을 재나 |
|---|---|
| 같은 앱 안 창 전환 | 앞에 있는 앱이 자기 창끼리 포커스를 바꿀 때(⌘\` 같은 키보드 전환). 바뀐 창 바로 아래에 Frost가 깔리기까지의 시간. 손쉬운 사용 권한이 있으면 알림으로, 없으면 0.1초 확인으로 따라간다 |
| 뒤에서 다른 창이 올라올 때 | 앞에 있지 않은 앱의 창이 맨 위로 올라올 때. 알려주는 신호가 없어 0.1초 확인으로 따라간다 |
| CPU · 메모리 | 측정 직후 10초 동안 Frost 프로세스의 평균 CPU와 메모리 |

"놓침"이나 "측정 못 함"이 나오면 측정 중에 다른 앱이 앞으로 온 것이다. 손을 떼고 다시 돌린다.

### 최근 결과

측정: 2026-11-03, macOS 26.6.2, MacBookPro18,3 (Apple M1 Pro), 손쉬운 사용 권한 켬

| 측정 | 평균 | 최대 | 횟수 |
|---|---|---|---|
| 같은 앱 안 창 전환 (⌘`처럼) | 27ms | 37ms | 12 |
| 뒤에서 다른 창이 올라올 때 | 61ms | 107ms | 9 |
| CPU · 메모리 (10초) | 1.0% | 59M | |

### 지금까지 바뀐 것

| 변경 | 같은 앱 안 창 전환 | 뒤에서 창이 올라올 때 |
|---|---|---|
| 처음: 0.25초마다 확인 | 최대 약 250ms | 최대 약 250ms |
| 0.1초마다 확인으로 줄임 | 평균 약 65ms | 평균 약 60ms |
| 손쉬운 사용 알림을 받음 | 평균 약 30ms | 그대로 (신호가 없음) |

## 3. 직접 확인

Frost는 스크린샷에 안 찍힌다. 화면으로 확인할 때는 `main.swift`의 `window.sharingType = .none`을 `.readOnly`로 바꾸고, 번들 ID를 다르게 한 복사본으로 찍는다.

| 기능 | 확인 방법 | 결과 | 마지막 확인 |
|---|---|---|---|
| 스크린샷 · 녹화에 안 찍힘 | 창 목록에서 Frost 창의 공유 상태가 0(캡처 제외)인지 보고, 실제 캡처에 흐림이 없는지 본다 | 통과 | 2026-11-03 |
| 캡처를 시작해도 앞 창이 안 흐려짐 | `screencapture -i`를 띄운 채 창 순서를 기록한다 | 통과 | 2026-11-02 |
| Mission Control에 안 보임 | 캡처용 복사본을 켜고 Mission Control 화면을 찍는다 | 통과 | 2026-11-03 |
| 전체 화면 앱 | 테스트 창을 전체 화면으로 바꾸고 창이 선명한지, 나오면 다시 덮이는지 본다 | 통과 | 2026-11-03 |
